Super Pang Saturn project changes (R06)
--------------------------------------
Base: Jo Engine 2026.3. The complete upstream license above is retained.
The project retains the documented PCM loop/prepared-start extensions of
the previous release. R06 adds an allocator-owned alternate NBG1 bitmap,
queues its presentation against the VDP1 displayed frame tag during VBlank,
and exposes the actual presented VBlank for scene-time accounting.
Changed engine files: jo_engine/vdp2.c and jo_engine/jo/vdp2.h.
The application disables printf to reserve both bitmap pages.
See docs/VALIDATION.md and verification/r06/code_review.md for scope and tests.


Super Pang Saturn project changes (R10_R3)
-----------------------------------------
Base remains Jo Engine 2026.3; upstream license above is unchanged.
Local fs.c / jo/fs.h changes classify complete CD responses before execution
flags, retain sector transfer closure across WAIT/cancellation, throttle empty
sector queries and expose passive diagnostic snapshots. audio.c changes bound
urgent no-progress retries by VBlank rather than host loop iteration count.
core.c / jo/core.h expose three bounded VBlank probes for an optional diagnostic
module. The application keeps all division-register restoration after the probes.
See docs/VALIDATION.md and verification/r10_r3/independent_review.md.
